# 4takeaway Login

Vue 3 login page UI for the 4takeaway food delivery app.

## Features

- Email + password login with inline validation
- Password visibility toggle
- Remember me (localStorage)
- Sign in with Facebook, Google, Apple (stubs)
- 4 UI states: default, filled, error, disabled

## Stack

Vue 3 · Tailwind CSS · Vite · Vitest

## Dev

```bash
npm install
npm run dev      # localhost:5173
npm test         # 14 tests
```
